YatraAI - Smart Train Travel Assistant

YatraAI is a production-ready AI-powered train travel chatbot built to simplify Indian railway travel through natural-language conversations. Acting as a virtual travel agent, it enables users to search trains, check schedules, view seat availability, and check PNR status through an intelligent chat interface. The system combines FastAPI, Python, JavaScript, SQLite, and LLM-based function calling, where the AI understands user intent and invokes dedicated tools for accurate data retrieval. It features a modern, responsive UI with dark mode, glassmorphism, and smooth animations, while its modular backend and simulated railway API layer are designed for easy integration with real-time railway services. The project demonstrates practical implementation of Generative AI, API orchestration, conversational AI, asynchronous backend development, and full-stack application architecture.
