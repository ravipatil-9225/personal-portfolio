# Personal Portfolio

Welcome to my personal portfolio website! This project showcases my skills, projects, achievements, and provides a way to get in touch with me.

You can view the live website here: 👉 [https://ravipatil-9225.github.io](https://ravipatil-9225.github.io)

## Features

* **Resume Link:** Easy access to download or view my resume.
* **Projects:** A showcase of my work with hyperlinks to live demos or source code.
* **Achievements & Participation:** Highlights of my extracurricular activities and milestones.
* **Skills Dashboard:** A dedicated section displaying my technical skills.
* **Contact Form:** Integrated with [Web3Forms](https://web3forms.com/) for easy communication.

## Project Structure

The project is divided into two main parts:

* `frontend/`: Contains the user interface and frontend assets.
* `backend/`: Node.js server handling backend functionality (like email processing).

## How to Run Locally

To run this project on your local machine, you will need [Node.js](https://nodejs.org/) installed.

### 1. Start the Backend

Open a terminal, navigate to the backend directory, and start the server:

```bash
cd "D:\Personal Portfolio\backend"
node server.js
```

### 2. Start the Frontend

Open another terminal, navigate to the frontend directory, and serve the application (this uses `serve` on port 3000):

```bash
cd "D:\Personal Portfolio\frontend"
npx -y serve -l 3000
```

The application should now be accessible at `http://localhost:3000`.
